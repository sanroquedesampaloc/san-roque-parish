# San Roque de Sampaloc Parish Website

## Project

A public website for San Roque de Sampaloc Parish providing Mass schedules, announcements, events, homilies, ministry information, sacrament guides, and parish contact details.

## Developer

NEXFORA Digital Innovation

## Audience

- Parishioners seeking Mass times, announcements, and event information
- Visitors looking for sacrament requirements or parish contact details
- Parish staff managing content through Sanity Studio at `/studio`

## Phases

### Phase 1 — Foundation & CMS (current)

- Next.js project setup
- Sanity CMS integration and content modeling
- Studio organization and validation

### Phase 2 — Public Website

- Homepage and page templates
- Content rendering from Sanity
- Responsive design and accessibility

### Phase 3 — Integrations

- Resend (email / contact forms)
- Cloudflare Turnstile (form protection)
- Sentry (error monitoring)

### Phase 4 — Testing & Launch

- Playwright end-to-end tests
- Performance optimization
- Vercel deployment
